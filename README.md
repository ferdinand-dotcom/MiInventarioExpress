# MiInventarioExpress

Aplicación web de gestión de productos desarrollada con **Node.js, Express, MongoDB Atlas y Socket.io** como parte de la unidad 2 de Aplicaciones Web.

## Estudiante
- Nombre:Nelson Coque
- Materia: Aplicaciones Web
- Universidad: UPS
- Año: 2025

## Funcionalidades
- Autenticación (login/logout) con sesiones.
- CRUD completo de productos (crear, listar, editar, eliminar).
- Almacenamiento en MongoDB Atlas con Mongoose.
- Carga de imágenes de productos con Multer.
- Validación de formularios con express-validator.
- Chat en tiempo real entre usuarios autenticados (Socket.io).
- Estructura MVC.

## Requisitos
- Node.js 18+ instalado
- Cuenta de MongoDB Atlas y cadena en `.env`
